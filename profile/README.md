> *You are in a maze of [twisty little passages](https://twistymaze.net), all alike.*

Welcome. These are the personal projects of Erv Walter ([@ervwalter](https://github.com/ervwalter)),
built and maintained in spare time.

### Apps

- **[Longhand](https://github.com/twistymaze/longhand)**: note-taking app for meetings and
  conversations. You type short notes, it records and transcribes the audio on your computer,
  and then turns your notes into a full summary. Live at [longhand.md](https://longhand.md).
- **[TrendWeight](https://github.com/twistymaze/trendweight)**: tracks weight trends,
  smoothing daily fluctuations so changes over time are easier to see.
  Live at [trendweight.com](https://trendweight.com).
- **[games.ewal.net](https://github.com/twistymaze/games.ewal.net)**: my BoardGameGeek
  collection and play statistics. Live at [games.ewal.net](https://games.ewal.net).

### Tabletop gaming

- **[swade-dice](https://github.com/twistymaze/swade-dice)**: 3D dice roller for
  Savage Worlds Adventure Edition (SWADE) in Owlbear Rodeo.
- **[swade-initiative-tracker](https://github.com/twistymaze/swade-initiative-tracker)**:
  card-based initiative tracker for SWADE in Owlbear Rodeo.
- **[secret-roll-deck](https://github.com/twistymaze/secret-roll-deck)**: generates a
  fair-mix card deck for Pathfinder secret d20 rolls.

### Kanka

- **[python-kanka](https://github.com/twistymaze/python-kanka)**: Python library for the
  [Kanka](https://kanka.io) API. Docs at [python-kanka.ewal.dev](https://python-kanka.ewal.dev).
- **[mcp-kanka](https://github.com/twistymaze/mcp-kanka)**: MCP server that lets AI
  assistants read and edit Kanka campaigns.
